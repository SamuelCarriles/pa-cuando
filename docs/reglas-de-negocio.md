# Reglas de negocio

## RN-01 — Acceso condicionado a la verificación

Solo las cuentas verificadas pueden acceder
a las funcionalidades relacionadas con las incidencias.

## RN-02 — Responsabilidad y asignación de incidencias

Cada área de atención tiene un único encargado responsable de gestionar las incidencias que le correspondan en la plataforma.

El usuario reportante selecciona el área a la que considera que pertenece su incidencia. El encargado responsable recibe las incidencias de su área, gestiona su seguimiento, actualiza su estado y se comunica con el reportante.

El encargado responsable puede reasignar una incidencia a otra área. Un encargado no puede reasignar incidencias que estén bajo la responsabilidad de otra área.

Cuando cambia el encargado responsable de un área, las incidencias sin resolver de esa área pasan a estar bajo la responsabilidad del nuevo encargado.

La ejecución material de las tareas puede corresponder a trabajadores que no necesitan disponer de una cuenta en la plataforma.

## RN-03 — Cambio del área de una incidencia propia

El usuario reportante puede cambiar el área asignada a una incidencia creada por él mismo mientras esta no esté siendo atendida.

Una vez que la incidencia está en proceso de atención, el reportante no puede cambiar directamente el área asignada. Si considera que la incidencia corresponde a otra área, deberá comunicarlo al encargado responsable, quien podrá evaluar y realizar la reasignación.

El reportante no puede cambiar el área de incidencias creadas por otros usuarios.

Todo cambio de área debe quedar registrado en el historial de la incidencia, incluyendo el área anterior, la nueva área, quién realizó el cambio y cuándo ocurrió.
