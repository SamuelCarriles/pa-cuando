# pa-cuando

Plataforma para reportar incidencias de residencia y facultad, asignarlas a un encargado y seguir su estado.

## Desarrollo

El proyecto puede desarrollarse utilizando Node.js y npm, o mediante el entorno reproducible proporcionado por Nix.

Si utilizas Nix, consulta la [guía de desarrollo](docs/development.md) para configurar el entorno, ejecutar la aplicación y publicar imágenes Docker.
